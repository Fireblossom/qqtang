# F8名字牌与本机箭头

2026-11-04。v848普通调用链、真实键盘更新和名字牌VM更新/绘制实跑；对应 `battle/scene.py` 的 `_draw_nameplate`，复用现有EffectPlayer。修正清单中“比武不知道哪个键开名字牌”的记录。

## 开关来自共享键盘对象

`0x005A4B6E` 的第23项为DirectInput F8（0x42）；`0x005A4C52` 按下沿翻转键盘 `+0x23`，按住不重复翻转。释放只恢复下一次按下资格。初始值0。

命令组件 `0x00610142` 每帧通过 `0x005A4C2F` 读取此位，调用 `0x005D2E80` 写全局显示位 `0x0085DB68`。该组件注册于普通和特殊规则，并无聊天框检查；F8也不受 `CanUseItemKey` 的道具键锁位限制。与Tab不同，F8不选槽也不发游戏报文。

这个键盘对象属于应用，不随每局重建。宿主现将开关存于UIRuntime，房间与战斗共用；聊天房间原有默认反向显示逻辑保留。房间和战斗都按按下沿处理，避免SDL的重复KEYDOWN反复翻转。

## 本机箭头与其他人的名字牌不同

构造 `0x005D2E8A`、初始化 `0x005D2F2B` 按IsLocal分支：

| 对象 | 绘制 |
| --- | --- |
| 本机角色 | `effect/playerArrow.eff`，不受F8控制；不画自己的名字牌 |
| 其他角色 | F8开时画misc171底图和昵称，关时不画 |

更新入口 `0x005D2F96 → 0x01136800`，绘制入口 `0x005D3017 → 0x01136880`；两条VM路径均成功执行。远端底图为83×25，锚点(21,78)，位于角色坐标；昵称12px、黑色阴影偏(1,1)，队伍与本机相同用绿色 `0xFF00FF00`，不同用黄色 `0xFFFFFF00`。水平居中使用 **GBK字节长度×3**，不是Unicode字符数×3。

给定本机(100,200)、远端(160,240)、昵称“糖六”，原生输出：底图绘制位置(127,163)，黑字(158,170)，黄/绿字(157,169)。ASCII `Bob_7` 为黑字(155,170)、绿字(154,169)。宿主沿既有原版视口(8,21)到场地区(10,27)的转换绘制，即这些点加(2,6)；底图在宿主场地点的(-41,-98)，彩字在(-3×字节数+1,-92)。

本机箭头更新的实际效果点为角色原始坐标+(10,-44)，按同一效果视口转换后是宿主场地点+(2,-65)。原包 `playerArrow.eff` 使用magic128和magic127两条轨道，100ms/帧、600ms循环，后一条轨道在0/300/600ms的透明度为1/0/1。现直接交给已有EffectPlayer，不另画近似箭头；效果累计场景时间。

名字牌组件的这些结果不代表父角色全部遮挡/变身资格已验收。原版父绘制还会检查当前/前一位置的地图元素及变身对象虚表条件；宿主仍沿用现有角色绘制入口，完整逐状态遮挡及录像对照留作后续范围。
