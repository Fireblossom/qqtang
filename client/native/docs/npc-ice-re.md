# 规则8 NPC冰箱命中、速度覆盖与同步

2026-11-04。默认未变身NPC现接入冰箱0x1166：临时覆盖速度档2、十秒计时、重复命中刷新、过期恢复基础属性，以及仲裁/跟随同步。未把本轮扩大成完整变身、主动穿泡或freeze动作的图形复刻。

## 原版证据

`0x006034B4` 对本机玩家调用初始箱子爆破判定，并在本机为仲裁方时遍历NPC调用同一路径。`0x006032E0` 检查中心和±3px的五个点，至少四个点在3×3范围内才调用 `0x00603564`；冰箱分支发送0x1166，火箱对NPC发送0x0FA5（糖浆），不是人类的500伤害标记。

0x1166解码结构为u16实体编号＋u32 IsAvatar，没有时间戳。实际接收函数 `0x005FE9D2` 通过真实 `0x005A287F` 查角色，再调用 `0x005ACBB7`，创建 `0x005DB43B` 的十秒覆盖对象挂在Actor+3E8。其虚表+8 `0x005DB4A3` 返回2；真实受保护getter `0x0087E6CA` 在该对象存活时返回2，删除后重新读取基础速度。

这不是“速度减半”。原本1档NPC会从40px/s变成NPC表2档的100px/s，原本3档则降为100px/s；按原版结果保留。永久速度属性没有被改写，期间拾取的基础速度仍应在效果解除后生效。

对象更新 `0x005DB487` 先扣dt，严格小于0才删除。10000→1→0时仍返回2，下一次减成负值才恢复。重复0x1166重建覆盖对象，把计时重置10000。帧中先执行移动/发包，后更新效果计时，因此本次刚过期也不能倒改本次移动包的速度。

`0x0060C63A` 的火场检查只要包含10000冰场就选0x1166分支；已接入混合冰火场优先级，但冰冻速度状态本身不提供火焰免疫，离开冰场后仍可正常困泡。

## 生产接入

- `npcIceState` 与永久速度分开；路径前探、方向掩码、浮点移动、终点预测和移动报文统一读取有效速度。效果在物理/发包后推进，跟随端也推进自己的效果帧。
- 初始冰/火爆破现在包含仲裁方负责的NPC；持续冰场重复命中刷新十秒。糖浆6秒死亡、NPC身份和队伍胜负不被冰箱通知改变。
- 跟随端的移动包速度只供插值，基础属性仍由模板和拾取通知维护，避免把冰冻的2档永久写成基础速度。速度变化会立即触发移动包，不再等待心跳。
- 服务端此前只允许已登记NPC的0x1162观察。本轮扩展允许仲裁方上传NPC的0x1166，同时把死亡登记严格限制为0x1162非变身命中；冰冻保持代理权限。UDP自有包快捷路径之前也检查NPC观察权限，普通玩家不能借自己的包给NPC施加冰冻。迟到通知可应答，但不复活已退休实体。
