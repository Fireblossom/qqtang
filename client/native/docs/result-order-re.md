原生0x52字节显示行的 `+0x06` 是显示索引，按输入顺序赋0..N-1。`0x00613630` 取该索引，将行放在y=`255+27*index`；昵称绘制再加2，图片另按各自包装器及DIMG偏移处理。向量中的各行本身也保留输入顺序。

因此服务端报文本身可能已经按它的结算规则排列，客户端负责按行显示，不能再插入一层本机优先策略。更改只影响显示，不修改服务端胜负、奖励或发包顺序。
