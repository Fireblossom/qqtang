# 箱子NPC：路径栈、两层门控与默认碰撞

2026-11-04，接续 `box-ai-re.md` / `npc-follow-re.md`。生产现接入 `0x005B1EA6` 路径消费、`0x005DEF29` AIType2控制器、`0x005B0A88` 500ms门控、`0x006112AF` 移动命令计数；通用放泡资格 `0x005DF009` 另作隔离函数对照，不由规则8派发；默认移动复用引擎已有的原版碰撞/滑角解析器。此处记录整数阶段；后续默认float32位移与完整终点预测已接入，见 `npc-motion-re.md`。状态道具及原版帧率调度仍未全量等价。

## 路径与初始化

Go按起点→目标存储，与原版6字节向量方向相反。新逃生路线放在旧路线前面，保留起点和旧节点；随路函数逐项跳过失配节点，严格大于10次失配才吸附当前格中心并清空。近中心弹点后返回1仍可留下路线，随后本次走漫游回退；这些语义不再用“走到目标格后删一个Cell”近似。

前方检查用 `0x007F2BB4`，节点方向用于投影，当前朝向另传碰撞函数；站立时保留路线。失配后只剩方向9终点的原生异常查询也保留，移动命令9仍只执行停止。47项原生随路记录全部逐项比较返回值、节点、计数、位置与碰撞调用。

`0x005AFDFA` 初始化+77C为创建时场景时钟，+7CC/+7CE为当前行列，+7D8为初始朝向，+7C8为0；宿主同步初始化，避免第一次同格查询额外消耗随机数。

## 命令计数与500ms是两层逻辑

`0x006112AF` 的+8是命令对象的有符号字节，属于场景命令，不是每个NPC各有一个计数器：

- 普通规则阈值5，起始0时第7次调用决策；规则8阈值10，第12次调用决策。
- 决策返回方向0～3后计数归0。返回9时停止但不归零，下一次调用立即重试。
- 场景时间≤2999、角色状态不是1/11、移动控制器状态为7/8时都不计数、不决策。这里不擅自给7/8推断额外业务名称。
- NPC死亡/补生不重建场景命令，故计数不会随每个新NPC归零。辅助进程按自己的固定更新调用数推进，不把“12次调用”宣称为原版固定多少毫秒。

命令进入AIType2后，危险直接走避险；安全时才检查 `abs(int32(now-lastThink))>499`。未满足时维持当前朝向，满足则消费路径或使用同格漫游缓存。11项控制器上下文、9项时间门控及416项命令序列均与原版对照。

## 通用放泡资格与移动回退

通用控制器检查向量尾节点的 **第4字节kind是否为4**，不是第5字节。空路线、kind4或任一玩家在同行/列两格内才尝试寻路；同行条件不额外过滤墙或生命状态。原版 `0x005DF009` 的30组隔离执行同时核实短路调用，宿主保留独立函数对照；规则8不安装其调用入口。

`0x005B0598` 先找逃生并追加，之后 `0x005B08E0` 才检查实际放泡许可。因此容量已满但寻路成功，也要保留追加；寻路失败则保留原路线、不发泡。这些是通用AI函数的独立语义；此前把该路径用于规则8的生产代码及相应测试已撤下。

安全目标搜索失败时 `0x005B214D` 检查各方向 **当前位置±40px**，不是当前位置，也不是强行换成下一格格心。顺序为右/上/左/下，最后两个判断保留原版反向分支：左不可通时返回左；左可通且下可通时返回9，否则返回下。两种位置（含非格心）×16种可通组合共32条，比较方向、检查顺序及实际坐标。原 `box_ai_v848.jsonl` 前374条保持不变，追加后共406条。

后续执行完整命令派发及默认角色帧更新，确认规则8不注册普通放泡命令；已移除旧500ms自动放泡。普通规则的每帧调用作为正对照，详见 `npc-rule-dispatch-re.md`。

## 默认碰撞、网络和火焰（整数阶段记录）

`Engine.MoveRuleNPC` / `RuleNPCPositionPassable` 为已注册NPC提供原版整数移动内核，不插入参与者、胜负队伍或策略观察。默认能力下复用19px前沿、方向地形位、三像素泡边界、40px单次位移上限、半身滑角及到格心的截断；规则8的12个角部禁入格亦用于NPC。动作命令保持期间持续移动，不再在每个格心等下一次规划。

方向掩码改为四个方向实际试算解析器，包括可以滑角的情况。NPC仍使用整数px/s换算和整数坐标，三档为123px/s；不足一像素的合法性探测使用至少一像素的试算。这些不是原版float32逐帧积分全等，边界仍可有像素差。

移动包终点跟随实际位移轴；滑角轴切回主轴时立即更新终点。受阻终点是当前位置，但原版发送端仍保留命令walk位，不能用“位置不变/已到终点”擅自清掉它。跟随端亦保留报文walk位。当前终点是可靠的短线段预测，不宣称已复刻 `0x005CF9B8` 全部前向预测。

连续移动另暴露旧NPC命中遗漏：只检查“本次刚生成的火焰”会忽略走进已有箱子火场。现按引擎规则8既有命中约定检查仍存在的火焰，进入后按当前时间困泡；对应新增回归测试，6秒死亡/玩家触碰击杀/补生保留。
