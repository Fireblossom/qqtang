# 对战玩家栏：等级、家族图腾与背景分支

2026-11-04。v848原版 `uiGame.py` / `levelCFG.py`、Client.exe玩家栏与开局回调调用点。本轮修复原有脚本初始化遗漏，头像和昵称位置沿用此前已验证的画法。

## 漏掉的是开局脚本回调

`0x005C87B0` 的开局处理调用 `ui_NotifyShowLevelIcon(points,seat,1)`。宿主已有原版uiGame、Level类、TLevelIcon、家族图腾资源，但一直没有调用这个函数；只画了头像、昵称和称号。因此它们始终保持class定义的 `visible=0`。

原版函数通过 `GetSeatInfo(seat)` 取得房间资料，再执行：

- `Level().getInfo(points)` 与 `Level().setUI()`：写入 `.levelIcon.mainLevel` / `.minLevel` 两张等级图片。其规则在原版 `levelCFG.py`，不改用Client.exe的文字称号表。
- `.level<seat>` 位于玩家栏(98,130+51×seat)，玩家栏原点为(609,0)，即屏幕(707,130+51×seat)。TLevelIcon两张图片共用39×15区域、保留原有帧方案/速度。
- `.kintotem<seat>` 位于(98,110+51×seat)，即屏幕(707,110+51×seat)，16×15。图案ID取 `m_stKinFlagID.m_iFlagID`，允许0～48，路径为 `object/ui/kinTotem/%03d.img`；没有图案则留空。
- `bRecord` 或玩家UIN为0时不显示。原版录像条件与空座位处理仍由脚本决定。

宿主开局先隐藏八个座位的旧图标，再按实际座位和开局竞技积分调用显示；玩家离场时隐藏其旧座位。缓存上次的座位/玩家/积分，避免每帧重设图片而重启动画。探险模式仍用自己的PVE面板。

## 灰底与名片需要分开核对

原包UI脚本的基础背景为 `object/ui/game/dlg_playerList.img`。Native玩家行构造 `0x005E1B1B` 将附加背景/名片指针初始化为0；`0x005E1C24` 另有角色 `+0x3D8/+0x3DC` 与 `+0x3E0/+0x3E4` 控制的两个分支，创建类型30/31图片并切换动作，绘制在头像/文字周围。`0x00447750` 确认类型30为Namecard、31为NamecardBound。

这说明存在装备背景和边框的独立路径，不能把旧录像中灰底直接当成所有玩家行的固定底色。其具体资源解析/动作回退、房间装备数据到角色字段的对应，以及旧录像的装备情况尚未完整核对；本轮保留原包默认背景，不添加一层猜测的灰色矩形。也没有把这些装备卡图标当作本轮恢复的等级/家族图腾。

## 默认底色的进一步实跑

开始只看RGB把面板空白处记成黑色，随后核对RGBA发现这些像素实际为 `(0,0,0,0)`，是透明孔，不能单凭它判断原版底色。进一步执行/检查后得到：

| 环节 | 证据 |
| --- | --- |
| Client.exe玩家行 | 真实 `0x005E1B1B/0x005E1C24/0x005E1DFF/0x005E1E46`，座位0/3/7的默认背景 `+0xC`、名片 `+0x58`、边框 `+0x5C` 均为0；只画头像和文字 |
| 面板资源 | 191×600画布，首帧偏移(7,0)；本轮三个玩家行孔洞采样RGBA均为0 |
| gameUI.dll默认控件底色 | 实际执行 `0x1002629C` 将默认bkcolor写为0；基类 `0x1002650D` 把它写到控件 `+0xC8`，即透明 |
| GFX.dll清屏 | 实际执行 `0x10004B57`，Direct3D Clear参数为count=0、rects=0、flags=1、color=0、depth=1、stencil=0。普通脏区清屏 `0x100075C1` 的两个分支源码同样传color=0 |

因此，在本轮验证的默认路径上，透明面板后面是黑色清屏，宿主黑底与当前v848一致；没有依据把所有玩家行改成灰色。这个结论来自上述链路，**不是把透明图片本身当成固定黑底**。旧录像灰底究竟由不同版本还是其他绘制/装备状态产生仍未确定。

另外执行真实 `0x0061FD25 → 0x00447BD0` 文件名生成：动作1=stand、2=trigger、4=walk。namecard2的stand/walk存在，trigger不存在；样本namecardbound1三个动作均不存在。本轮不擅自把动作2改读walk，也没有假定完整资源管理器存在动作回退。

可复跑：
