# 默认NPC模型：freeze/birth空槽、动作切换与阴影

2026-11-04。本轮补齐默认模型构造到实际绘制的证据，修正规则8 NPC画面，并纠正上一轮把条件加载的birth动画当成默认出生画面的结论。出生状态/Ready计时移植仍有效；图片是否加载是另一层。

## 默认构造与显式加载不是同一路径

`0x005CB15C` 使用真实模型构造 `0x00424460`。后者创建普通部件 `0x00425730` 和两个辅助部件；`0x00426950→0x00425D60` 根据原包INI加载动作。配置表 `0x007DB120/13C` 只有 `[1,4,2,6,10,8,11]`，即stand、walk、trigger、die、win、lose、wait。

默认模型没有加载动作7（freeze）或14（birth）。`0x00424A60` 切动作只修改已有部件的动作号，不自动补其图片；`0x004264E0` 在当前数据槽为空时跳过主体，`0x00425220` 仍绘制阴影。没有自动回退stand/walk。

已执行完整模型总构造、普通/辅助部件构造、真实角色后处理 `0x005AF9F3`、冰冻/移动/停止设置、角色帧及 `0x005B528F→0x00425220→0x004264E0` 绘制，默认7/14均只产生阴影调用；站立、行走、困泡主体作为正对照。默认衣服与其他普通部件同样受空槽判断，未遗漏两个辅助部件。

对水手等六种Boss，birth文件确实存在。显式调用 `0x004268F0(14)` 后，才经 `0x00425F10` 加载并绘出它；这是与默认构造不同的阳性对照。旧 `probe_boss_birth_animation.py` 手动装入14后得到200ms/帧、单次播放的结论在该条件下成立，不能证明实战默认装入。此前宿主主动读取birth文件的行为现已撤下。三个箱子怪的freeze图片不存在，本轮没有生成替代素材。

## 速度效果与图片动作分开

`0x005ACBB7→0x005B4EFE` 设置动作7。随后行走控制器 `0x005C07FE→0x005AC982→0x005B4E3B` 选择动作4，停止 `0x005C07D6→0x005AC934→0x005B4DFB` 选择动作1；冰冻速度覆盖此时仍可有效。重复同一动作与朝向不重置图片帧，转向才重置。

`0x00425020` 在动作4时把dt乘2；部件图片周期仍200ms，因此正常行走每100ms进一帧。困泡主体动作2不乘2，为200ms/帧，朝向固定270。宿主对箱子NPC使用独立 `picture_action/picture_facing/picture_clock`；不再根据moving或iced直接猜姿态。移动/停止恢复主体不会提前取消十秒速度覆盖。

仲裁方在命令后推进图片帧；跟随端先推进旧图片，再由实际消费的新移动记录切动作，符合 `0x005ABE96` 的图片更新先于远端插值、`0x005D1348` 才执行行走/停止设置的次序。同一插值记录不重复重置。后续实际执行收包队列发现TimeStamp不是未来执行期限，已撤下按时间戳等待切姿态的近似；原版解码后接收队列及两种回正已接入，见 `npc-remote-queue-re.md`。

## 默认阴影

真实阴影编号 `0x07008301` 转换为 `object/misc/misc131_stand.img`。`0x00424990` 的阴影宿主位置相对衣服画布为(+30,+59)，原图34×25、帧偏移(+3,+11)。宿主沿现有画布基准在场景原点＋实体位置−(20,5)绘制，保留DIMG偏移；规则8 NPC和默认Boss均绘制，空动作槽时也保留。Boss出生期血条照常显示。

## 基准与范围

```sh
.venv/bin/python tools/probe_npc_picture.py /path/to/client-patched
```

`npc_picture_v848.jsonl` 共135条：九角色×14个默认路径检查点（126条）和九个显式加载对照。角色为25/26/27/24/28/32/34/35/36。记录实际已加载动作槽、绘制资源、原生帧/余数、重置后累计图片时钟、朝向、冰冻对象及阴影/衣服位置。图片时钟通过观察原生重置/更新函数取得；过期行实际运行501个20ms角色帧并保持行走命令，覆盖十秒后主体动作不随效果消失而跳变。

INI值作为真实资源输入，方向帧布局、纹理上传、裁剪窗口、空辅助部件的排序及阴影设备为控制依赖。原生模型/部件构造、加载选择、演员操作、更新和绘制门控未替换；不把设备回调观测称为Windows/D3D逐像素验证。颜色拟合、完整遮挡/变身、长帧跳帧及全部网络队列仍为独立范围。

Go逐项比较126个默认事件的动作、朝向与时钟；Python用原生输出比较主体有无、正常固定20ms链路的帧选择、阴影相对位置及默认birth与显式加载的区别。人类、探险及其他旧绘制路径的动画时钟未借此全部改写。
