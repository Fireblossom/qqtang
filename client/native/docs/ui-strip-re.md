# 房间角色属性DYSTRIP分派

2026-11-04。原版角色提示使用 `DYSTRIP`，宿主原先把它当普通图片，只画15px原图；当前/上限数值虽已设置，却没有按控件110px宽度显示。现接入共用填充绘制。

原版工厂 `0x100019BF` 将DYSTRIP构造为 `0x10011788` / 虚表 `0x1003DFD8`；动态生命条由 `0x10011BF3` / `0x1003E0B8` 派生，两者共享 `0x1001192F`。因此直接复用已有生命条三段端帽算法；同时把阈值和填充宽度计算按原版float32舍入。

泡数、威力、速度资源均15×15，端帽各5px；玩家生命条资源3×5，端帽各1px。填充宽度为控件宽×当前/总量：当前≤0.01、当前大于总量、填充不足1px时不画；中段不足1px时整图缩放，否则保留两端并拉伸中段。默认绘制颜色由真实全局初始化 `0x10026279` 设为白色。

```sh
.venv/bin/python tools/probe_ui_strip.py /path/to/client-patched
```
